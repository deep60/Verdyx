# extractor and every library that shapes a feature value must not drift.

# thrember was written for signify 0.7, but every version below 0.9.2 has a
# high-severity advisory in its authenticode parser (GHSA-p4hh-mq57-gq8x), and
# this service parses signatures in untrusted uploads. 0.9 moved SignedPEFile
# and renamed its iterator; pe_features.py adapts it so thrember's code runs
# unchanged. Checked on 229 real Windows programs (120 signed): every feature
# value is identical to signify 0.7.1's.
